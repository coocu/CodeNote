학원 출석 관리 시스템

여러 학원에서 학생 등록과 출석체크를 함께 사용할 수 있고,
학부모는 하나의 앱에서 등록된 학원의 출결을 통합해 확인할 수 있는 출석 관리 시스템입니다.

학생 등록 NFC 출석 출석번호 입력 학부모 출결 확인 다중 학원 지원
AndroidGoogle Play 다운로드 iOSApp Store 준비 중
01

학원별 학생 등록

학원 관리자가 학생을 등록하면 해당 학원에서 출석 시스템을 사용할 수 있습니다.

1

학원별 등록

같은 학생이라도 각 학원에서 등록되어야 해당 학원의 출석 알림과 출결 확인을 사용할 수 있습니다.

2

여러 학원 이용

학생이 여러 학원을 다니는 경우 각 학원에서 등록한 뒤 하나의 출석 시스템으로 이용할 수 있습니다.

3

출석번호 지원

NFC 카드가 없어도 등록된 출석번호를 이용해 출석체크를 할 수 있습니다.

4

NFC 카드 연결

학생에게 NFC 카드를 등록해 빠르게 출석체크할 수 있습니다.

02

NFC 카드 하나로 여러 학원 출석

같은 시스템을 사용하는 학원이라면 학생이 각 학원에 등록된 뒤 하나의 NFC 카드를 계속 사용할 수 있습니다.

학생 등록각 학원에서 등록
→
NFC 연결학생 카드 등록
→
출석체크등록 학원에서 태그
→
출결 확인학부모 앱에서 확인
NFC 카드 사용 카드에는 학생 이름이나 보호자 전화번호 같은 학생정보를 직접 기록하지 않고, 시스템에서 사용하는 식별값으로 출석을 처리합니다.
03

간편한 출석체크

NFC 카드를 태그하거나 4자리 출석번호를 입력해 출석을 처리할 수 있습니다.

NFC 출석

등록된 NFC 카드를 태그해 출석체크를 빠르게 처리합니다.

출석번호 입력

학생별 4자리 출석번호를 입력해 카드 없이도 출석할 수 있습니다.

04

학부모 통합 출결 확인

자녀가 여러 학원을 이용해도 등록된 학원의 출결을 하나의 앱에서 함께 확인할 수 있습니다.

A

학원별 출결 확인

등록된 학원별로 자녀의 입실·퇴실 기록을 확인할 수 있습니다.

B

하나의 앱으로 통합

학원마다 별도의 출석 앱을 사용할 필요 없이 하나의 앱에서 여러 학원의 출결을 확인합니다.

C

출석 알림

학생이 등록된 학원에서 출석이 처리되면 해당 학원의 출결 알림을 받을 수 있습니다.

D

여러 학원 연동

같은 출석 시스템을 사용하는 학원에 학생이 각각 등록되어 있으면 학원별 출결을 함께 관리할 수 있습니다.

05

PC 관리자 지원

학원 관리자는 PC 화면에서 학생 등록과 출석 관련 관리 기능을 사용할 수 있습니다.
