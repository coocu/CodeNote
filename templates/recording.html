01

빈 연습실 예약

방과 날짜·시간을 선택하고 내 예약을 확인·변경합니다.

02

학원에 맞는 운영 정책

연습실·회원·운영시간과 예약 가능 범위를 구성합니다.

03

01

원생/강사 앱 사용

학원에서 등록된 이용자는 앱에서 학원을 선택한 뒤 자신의 등록 정보로 로그인해 예약 기능을 사용합니다.

1

연습실 선택

사용 가능한 연습실을 확인하고 원하는 방을 선택합니다.

2

날짜·시간 예약

운영시간과 기존 예약상황을 확인하면서 가능한 시간을 선택합니다.

3

내 예약 관리

예약 전에는 시간 변경·방 이동·취소를 사용할 수 있으며 이용 중에는 지원되는 종료/이동 기능을 사용할 수 있습니다.

4

연습일지

완료한 연습 기록을 확인하고 필요한 경우 연습내용을 남길 수 있습니다.

02

관리자 기본 설정

학원 등록과 관리자 로그인 이후에는 먼저 연습실과 회원 정보를 구성합니다.

권장 초기 설정 순서 연습실 등록 → 운영시간 설정 → 카테고리 구성 → 원생/강사 등록 → 예약정책 확인
03

운영 중 관리

예약 현황과 방별 이용상태, 월별 이용순위까지 관리자 화면에서 확인할 수 있습니다.

예약현황

예약·취소·이용중 종료 상태와 예약시간을 확인하고 필요한 관리 작업을 수행합니다.

연습실 현황

각 방의 시간대별 빈 시간과 예약상태를 한눈에 확인합니다.

이용현황

월별 누적 이용시간과 카테고리별 사용현황을 확인합니다.

예약 관리

관리자는 필요할 경우 회원 예약을 등록하거나 기존 예약을 관리할 수 있습니다.

04

연습일지 관리

학생별 연습기록과 누적 연습시간을 확인하고 관리자가 직접 일지를 등록할 수도 있습니다.

관리자 직접 등록 회원 선택 → 연습일지 등록 → 날짜/시작시간/종료시간 지정 → 연습내용 입력 → 등록
05

백업과 복원

관리자 화면의 백업/복원 메뉴에서 로그인 이후 운영 데이터를 ZIP으로 보관하고 필요할 때 복원할 수 있습니다.

ZIP 백업

회원, 카테고리, 연습실, 운영시간, 예약, 이용기록, 연습일지 등 운영 데이터를 보관합니다.
